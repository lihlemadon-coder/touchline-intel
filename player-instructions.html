Instruction categories

Know which side of the ball.

Attacking instructions

Defensive = player stays back when we attack; use for DMF and Defensive Full-backs.

Anchoring = player stays in his position; use only for Target Man.

None = player plays normal; use for attacking full-backs and wingers who need to go forward.

Defensive instructions

Counter Target = player stays up front when we defend, ready for counter; the general guideline is max 2 attackers.

Man Marking = assign to Destroyer DMF to mark opponent's playmaker.

None = no individual defensive instruction.

Setup note: Fabio Capello's requested setup below assigns Counter Target to LW, RW, and CF (three players), following that coach-specific setup despite the general max-2 guideline.
